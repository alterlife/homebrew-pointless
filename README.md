# Pointless Homebrew Tap

Official Homebrew Cask tap for [Pointless](https://github.com/alterlife/pointless) — cursor-free keyboard navigation for macOS.

## Installation

```bash
brew install alterlife/pointless/pointless
```

Or tap first:

```bash
brew tap alterlife/pointless
brew install --cask pointless
```
